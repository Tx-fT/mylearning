  ▎ 没有 Docker，你交出去的是「代码 + 一页可能漏掉的安装说明」；
  ▎ 有 Docker，你交出去的是「一个打开就能跑的箱子」。
它就是"你的后端 + 它活着的完整环境"，一个能带到任何地方的箱子。

  命令里那几个"小开关"（容易忘，记一下）

  - -d → 后台运行（关了窗口也继续跑）
  - --name sichu → 给容器起名（不起的话是随机乱码）
  - -p 8001:8001 → 端口映射，左边是你电脑的端口，右边是容器里的端口（"把容器的 8001 接到我电脑的 8001"）
  - --env-file src/.env → 把密钥文件注入容器（所以容器能拿到你的 API key）
  - -t sichu-backend → 给镜像打个名字标签

  今天学到的"坑"和"配置"（做一次就记住，不是天天做）

  1. 关梯子才能拉镜像/构建（Clash 会 EOF）—— 这是你环境特有的坑
  2. 镜像加速：改 daemon.json 加 registry-mirrors —— 配一次，终身受益
  3. pip 走清华源：Dockerfile 里加 -i https://pypi.tuna.tsinghua.edu.cn/simple —— 国内装依赖快

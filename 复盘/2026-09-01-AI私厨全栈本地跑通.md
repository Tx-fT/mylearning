## 核心命令
| 命令 | 作用 |
|---|---|
| `docker build -t 名 .` | 打包成镜像 |
| `docker run -d --name 名 -p 端口 镜像` | 跑成容器 |
| `docker ps` / `docker logs` | 看容器 / 日志 |
| `npm install` | 装前端依赖 |
| `npm run dev` | 启动前端 |
| `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` | 放开 PowerShell 脚本权限 |

## 踩过的坑
1. 拉镜像 / 构建要**关梯子**（Clash 会 EOF，把 Docker 流量发海外节点导致失败）
2. PowerShell 禁止脚本 → `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 解决
3. 中文 curl 编码（终端问题，浏览器里用中文没事）

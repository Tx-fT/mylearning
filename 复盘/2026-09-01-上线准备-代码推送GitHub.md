## 核心操作
| 操作 | 作用 |
|---|---|
| `git init` / `git add` / `git commit` / `git push` | 本地仓库 → GitHub |
| `ssh-keygen -t ed25519` | 生成新的 SSH key |
| `~/.ssh/config` 配 `IdentityFile` | 指定 github.com 用哪个 key |

## 踩过的坑
1. SSH key 绑在另一个 GitHub 账号 → 报「key already in use」→ 生成新 key 解决（一个 key 只能绑定一个账号）
2. Word 临时文件 `~$xxx` 会混进提交 → `.gitignore` 加 `~$*` 排除
3. 密钥安全：`.gitignore` 必须排除 `.env`（含 API key，绝不能传上 GitHub）

## 一句话总结
把本地项目推上 GitHub，是「上线」的第一步——云端平台（Render/Vercel）就是从 GitHub 拉代码来部署的。
